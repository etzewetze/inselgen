# InselGen 0.3.0

Vegetation, Seen, Erzadern und eine Bossbar für den Generierungsfortschritt.

## Neu

- Baum- und Pflanzendichte pro Insel mit `trees:0-100` und `plants:0-100` wählen.
- `tree:auto` wählt zum Biom passende Bäume; Arten lassen sich ausdrücklich auswählen.
- Eichen, Birken, Fichten, Tropenbäume, Akazien, dunkle Eichen, Kirschbäume, Mangroven und gebogene Palmen.
- Eigene Baumvorlagen unter `plugins/InselGen/trees/*.yml`, mit Beispielpalme und Reload.
- `lakes:0-8` erzeugt kleine Seen mit geprüftem, geschlossenem Ufer und festem Boden.
- `ores:true/false` aktiviert Erzadern im Steinkern der Insel.
- Bossbar mit gewichtetem Fortschritt für Planung, Prüfung, Platzierung und Abschluss; auch beim nativen Undo.
- Alle neuen Blöcke und Biomänderungen sind über das bisherige Undo rückgängig zu machen.

## Beispiele

```text
/skyinsel 300 biome:beach tree:palm trees:50 plants:10 lakes:2 ores:true
/skyinsel 200 32 bergig biome:birch_forest trees:80 plants:30
/skyinsel 150 tree:cherry trees:50 lakes:1
/skyinsel 150 trees:0 plants:0 lakes:0 ores:false
/skyinsel 200 biome:beach tree:example_palm
/skyinsel trees
```

Baumdichte ist der Anteil geeigneter Kandidaten, Pflanzendichte der Anteil geeigneter Grasblöcke. Bei ungeeignetem Gelände können weniger Seen entstehen. Auf Sand wachsen keine Grasbüschel. Ein fester Seed mit denselben Optionen wiederholt dieselbe Insel innerhalb dieser Pluginversion.

## Installation

**inselgen-0.3.0.jar** herunterladen, die alte InselGen-JAR in `plugins/` ersetzen und den Server vollständig neu starten. Bestehende Konfigurationen bleiben verwendbar. Neue Schlüssel sind optional: Standard sind 30 % Baumkandidaten, 8 % Pflanzen, `tree:auto`, ein See und aktivierte Erze. Einstellungen und eigene Baumvorlagen sind in der README beschrieben.

Unterstützt Spigot, Paper und Folia ab Minecraft 1.21. Java 21 als Pluginbasis; der Server kann eine neuere Java-Version benötigen, beispielsweise Java 25 für Minecraft 26.3. FAWE ist optional; Folia verwendet die native Platzierung.

Die Datei `inselgen-0.3.0.jar.sha256` enthält die Prüfsumme. Die Source-Code-Archive werden zur Installation nicht benötigt.

## Prüfung

84 automatisierte Tests erfolgreich. Generierung mit Seen, Erzadern, Palmen und eigenen Baumvorlagen, Bossbar-Fortschritt und Undo auf Paper 1.21.1, Folia 1.21.4 sowie Paper/Folia 26.3 geprüft. Paper 26.3 verwendet FAWE 2.16.2; die anderen Läufe die native Platzierung. Abbruch, Bossbar-Aufräumen, belegter Luftraum und partielles Undo zusätzlich auf Paper 1.21.1 und Folia 26.3 geprüft. Gegen die Spigot-1.21-API kompiliert; kein direkter Spigot-Serverlauf.
