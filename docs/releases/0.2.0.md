# InselGen 0.2.0

Erste öffentliche Veröffentlichung des Himmelsinsel-Generators.

## Funktionen

- Natürlich geformte, zufällige Inseln mit maximaler Ausdehnung von 50–500 Blöcken.
- Ovale Umrisse, Einbuchtungen, Hügel, Berge und zulaufende Felsunterseiten.
- Optional feste Seeds und die Stile `natuerlich`, `bergig` und `flach`.
- Biomauswahl mit Tab-Vervollständigung; Beach und Desert erhalten Sandboden.
- Kleine Eichen und Pflanzen auf geeigneten Grasflächen.
- Fortschritt, Abbruch und Undo einschließlich Biomänderungen.

## Beispiele

```text
/skyinsel 150
/skyinsel 200 bergig
/skyinsel 300 biome:beach
/skyinsel 300 32 bergig biome:beach
/skyinsel undo
```

Ohne Zahlen-Seed entsteht bei jedem Aufruf eine neue Form. Ein fester Seed wiederholt dieselbe Insel.

## Installation

Die Datei **inselgen-0.2.0.jar** aus den Release-Assets herunterladen, in `plugins/` legen und den Server vollständig neu starten. Beim Aktualisieren die alte InselGen-JAR ersetzen. Als OP in freien Luftraum fliegen, beispielsweise auf Y=200, und eine Insel erzeugen.

Die JAR ist für Spigot, Paper und Folia ab Minecraft 1.21 gebaut. Pluginbasis ist Java 21; neuere Server behalten ihre eigene Java-Anforderung, beispielsweise Java 25 für Minecraft 26.3.

FAWE ist optional. Auf Folia bzw. ohne FAWE erfolgt die Platzierung über die zuständigen Server-/Regionscheduler. Rückgängig: `/skyinsel undo`. Mit FAWE funktioniert auch `//undo`.

Die native Platzierung benötigt freien Luftraum und `inselgen.native` (standardmäßig OP). Sie besitzt keine WorldGuard-/PlotSquared-Anbindung. Große Inseln können dort mehrere Minuten benötigen. Weitere Angaben zu Konfiguration und Undo stehen in der README.

## Prüfung

47 automatisierte Tests erfolgreich. Biomwechsel und Undo wurden auf Paper 1.21.1/26.3 sowie Folia 1.21.4/26.3 geprüft. Gegen die Spigot-1.21-API kompiliert; kein direkter Spigot-Serverlauf.

Die Datei `inselgen-0.2.0.jar.sha256` enthält die Prüfsumme der JAR. Die automatisch angebotenen Source-Code-Archive werden zur Installation nicht benötigt.
