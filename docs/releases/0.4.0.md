# InselGen 0.4.0

Bäume und Inseln aus einer Auswahl speichern und mit verschiebbarer Vorschau wieder einsetzen.

## Neu

- `/inselgen export tree <Name>` speichert den markierten Baum als sofort nutzbare YAML-Baumvorlage.
- `/inselgen export insel <Name>` speichert alle Nicht-Luftblöcke der Auswahl als komprimierte Inselvorlage.
- WorldEdit-/FAWE-Quaderauswahl oder eigene `/inselgen pos1` und `pos2`, auch auf Folia ohne WorldEdit.
- `/inselgen import tree|insel <Name>` zeigt zunächst ausschließlich Vorschau-Blöcke beim ausführenden Spieler.
- Klickbare Buttons und `/inselgen move <vor|zurueck|links|rechts|hoch|runter> [1–100]` verschieben die Vorschau.
- `/inselgen confirm` prüft die Position und setzt die vollständige Vorlage mit Bossbar und Undo.
- `/inselgen cancel` verwirft die Vorschau; `/inselgen templates` listet gespeicherte Vorlagen.

## Beispiel

```text
/inselgen export tree meine_palme
/inselgen import tree meine_palme
/inselgen move vor 5
/inselgen move links 2
/inselgen move hoch 3
/inselgen confirm
/inselgen undo
```

Inseln entsprechend mit `export insel meine_insel` und `import insel meine_insel`. Ein eindeutiger Name kann ohne Typ importiert werden. Exportierte Bäume sind sofort mit `tree:meine_palme` beim Generieren verwendbar.

Die Vorschau startet acht Blöcke vor dem Spieler. Große Vorlagen erhalten eine vereinfachte Oberflächenvorschau mit Rahmen; `confirm` setzt sämtliche gespeicherten Blöcke. Die Vorschau verfällt standardmäßig nach fünf Minuten. Blockzustände und Wasser werden gespeichert; Biome und Entities werden nicht kopiert. Blöcke mit Zusatzdaten wie Kisten oder Schildern werden beim Export abgewiesen. Bestehende Namen werden nicht überschrieben. Details und Grenzen stehen in der README.

## Installation

**inselgen-0.4.0.jar** in `plugins/` legen, die alte InselGen-JAR ersetzen und den Server vollständig neu starten. Vorhandene Einstellungen und Baumvorlagen bleiben verwendbar. Neue Rechte `inselgen.export` und `inselgen.import` gelten standardmäßig für OPs, zusätzlich zu `inselgen.generate`; native Platzierung benötigt weiterhin `inselgen.native`.

Spigot/Paper/Folia ab Minecraft 1.21, Pluginbasis Java 21; neuere Server können eine neuere Java-Version benötigen. FAWE ist optional. `inselgen-0.4.0.jar.sha256` enthält die Prüfsumme.

## Prüfung

97 automatisierte Tests mit Java 21 erfolgreich. Baum-/Inselexport, clientseitige Vorschau ohne Weltänderungen, Verschieben, Bestätigen, Blockzustände, Verwerfen mit aktuellen Weltblöcken und Undo auf Paper 1.21.1, Folia 1.21.4 und Paper/Folia 26.3 geprüft. Paper 26.3 nutzt FAWE 2.16.2 und dessen Auswahl; die anderen Läufe verwenden eigene Auswahlbefehle und native Platzierung. Größere Vorlagen mit 4.840 Blöcken über mehrere Chunks inklusive reduzierter Vorschau und vollständigem Import/Undo zusätzlich auf Paper/Folia 26.3 geprüft. Gegen die Spigot-1.21-API kompiliert; kein direkter Spigot-Serverlauf.
